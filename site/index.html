Bring your own server

A small setup.
A space that's yours.

This is a self-hosted app, not a hosted service.
You'll need an account on your own Etebase server.

  1. 1

    Have a server ready

    Run an Etebase server and create an account. Already have one? You're ready for the next step.

  2. 2

    Install the Android app

    Get the APK from GitHub Releases. Choose the standard APK for most 64-bit phones, or the armeabi-v7a build for older 32-bit devices.

  3. 3

    Sign in. Make it yours.

    On the login screen, open Advanced settings, enter your Server URL, and sign in. Create your first note or save a link.

Is there a web app or an iOS app?

This page presents the Android app. The repository's web build is used for browser tests; it is not a hosted notes service. There is no iOS release offered here.

Moving from EteSync Notes?

Ciphwren Notes installs as a separate app. Sync the old app first, then install Ciphwren Notes and sign in to the same server. Check that your notes have synced before uninstalling the old app.

What should I know about privacy?

End-to-end encryption protects synced content, but doesn't make your device or server anonymous. You still manage your server, account, device security, and backups. This presentation site has no analytics, remote fonts, or third-party scripts; GitHub Pages hosts it.
